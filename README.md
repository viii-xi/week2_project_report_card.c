## 📌 Project Overview
This project is a **console-based C program** that generates a **Report Card** for students using **arrays, strings, functions, and loops**.  
It was developed as part of the **MotionCut Internship Program (Week 2 Task)**.  

---

## 🎯 Features
- Input **names and marks of 5 students**  
- Store data using **arrays**  
- Calculate **total marks, average, and grade** using **functions**  
- Display a formatted **report card**  
- Uses **loops** for input/output  
- **Grading Logic**:  
  - `A` → Average >= 90  
  - `B` → 75–89  
  - `C` → 50–74  
  - `D` → Below 50  

---

## 🛠️ Technologies Used
- **C Programming Language**  
- **GCC Compiler** (or any C compiler)  
- **Command Line / Terminal**
